# 亚克力面板下单说明（嘉立创面板）

顶盖顶部有一圈 **2.6 mm 宽 × 1.8 mm 高**的凸边框，边框内圈就是亚克力面板的位置：
面板 1.5 mm 厚 + **0.16 mm 背胶（皇冠 #513）**贴进去后，面板顶面比边框低 **0.14 mm**，
边框负责定位、包边和防磕碰（印刷面缩在边框里，平放、拿取都磨不到图案）。

所有面板参数都由 `enclosure.py` 从同一套外壳参数派生，所以 **DXF 永远不会和
打印出来的顶盖走样**；改任何参数后重跑一次即可。

```bash
cd hardware/enclosure
uv run enclosure.py        # → output/Panel.dxf（切割文件）
uv run panel_drawing.py    # → render/panel_drawing.png（带尺寸的核对图）
uv run panel_print.py      # → output/Panel_print_{front,back}.pdf/.svg（印刷图）
```

---

## 1. 上传什么

| 文件 | 用途 | 说明 |
|---|---|---|
| `output/Panel.dxf` | **切割文件**（激光） | 1:1、单位 mm、图层 `PANEL`，只含切割线：外形 + 3 键窗 + 旋钮孔 + 导光孔（16 直线 / 16 圆弧 / 2 圆，全部闭合轮廓） |
| `output/Panel_print_front.pdf` / `.svg` | **印刷文件 · 正面印刷** | 1:1、矢量、文字已转轮廓；图案就是正面看到的 |
| `output/Panel_print_back.pdf` / `.svg` | **印刷文件 · 背面印刷** | 同一张图**镜像**：印在亚克力背面，从正面看才是正的（耐磨、图案封在板内） |
| `render/panel_drawing.png` | 自己**核对尺寸**用 | 标注从面板自身左下角量起，下单前对一眼 |
| `render/panel_print.png` | 印刷图**核对图** | 印刷效果 + 尺寸标注 + 红色虚线标出 5 处开口位置 |

嘉立创面板支持 AI / DXF / CDR / PDF，DXF 直接上传即可。若页面提示「线条不闭合 /
解析失败」，通常是把它当成了印刷图解析：切回「切割」模式，或另存一份只保留 `PANEL`
图层的文件。

## 2. 下单参数

| 项 | 选什么 | 依据 |
|---|---|---|
| 产品类型 | **亚克力面板**（PC 更耐刮，也可） | 硬质面板才能嵌进边框 |
| 厚度 | **1.5 mm** | `PANEL_T`；边框高 `RIM_H` = 面板 1.5 + 背胶 0.16 = 1.66 → 向上取整到整层 **1.8 mm**（0.2 mm 层高 × 9 层），所以面板比边框低 0.14 mm |
| 背胶 | **皇冠 #513，0.16 mm**（白色半透明 PET 双面胶，粘性强、长期耐温 80 ℃） | `PANEL_TAPE`；边框比面板高 0.14 mm，胶稍厚也不会把面板顶出边框 |
| 表面处理 | 磨砂 / 亮面，+ 丝印或 UV 打印 | 磨砂能柔化导光孔的光斑 |
| 印刷 | 上传 `Panel_print_front.pdf`（正面）或 `Panel_print_back.pdf`（背面） | 背面印刷要把**切割文件与印刷文件分开**上传，并备注「镜像反面印」 |
| 颜色 | 透明 + 黑色丝印，或黑 / 白亚克力 | 透明 + 丝印最接近「面板」质感 |
| 尺寸 | **91.67 × 42.67 mm** | 上传后自动读图，核对一下 |
| 公差 | ±0.1 mm（常规） | 面板四周单边留 0.15 嵌装间隙（`PANEL_GAP`），公差正好吃掉 |

## 3. 关键尺寸（原点 = 面板左下角）

| 项目 | 数值 |
|---|---|
| 外形 | **91.67 × 42.67 mm**，外圆角 **R2.84** |
| 键窗 ×3 | **19.2 × 19.2，R2.1**，中心 (20.79, 11.27) / (41.43, 11.27) / (62.07, 11.27)，键距 20.64 |
| 旋钮孔 | **φ13.8**，中心 (79.21, 31.58)，距右边缘 12.46 |
| 导光孔 | **φ3.6**，中心 (35.14, 33.61) |
| 外圈边框宽 | 2.45 mm（激光切割无压力） |
| 最窄连接桥 | 键窗之间 **1.44 mm**（下方有顶盖支撑，不承力） |

对应顶盖上的开口（面板开孔必须 ≥ 它们，否则会被面板盖住）：

| 顶盖开口 | 尺寸 |
|---|---|
| 键窗 | 19.0 × 19.0 R2.0 |
| 旋钮 | 裙边沉台 φ13.6 × 0.8 深 / 套管过孔 φ8.6 |
| 导光 | 阶梯沉台 φ8.0 → φ5.2 → 出光孔 φ3.4 |

## 4. 三条不能动的红线

1. **外形不能放大**：顶盖边框内圈只有 91.97 × 42.97，单边 0.15 的嵌装间隙。超了
   塞不进去（要改就改 `PANEL_GAP`，然后重出 DXF）。
2. **键窗不能缩小**：19.2 = 顶盖键窗 19.0 单边放大 0.1（`PANEL_KEY_PAD`），用来
   吸收面板 ±0.1 的加工公差。缩到 19.0 会露出顶盖窗口内壁，甚至蹭到键帽。
3. **旋钮孔 / 导光孔必须与顶盖同心**：旋钮孔要露出 φ13.6 沉台（旋钮裙边要沉下去），
   导光孔要对准 φ3.4 出光孔。这两处位置都直接来自 PCB 的编码器 / LED 实测坐标。

## 5. 印刷层（图案）

印刷图由 `uv run panel_print.py` 生成，**和切割图完全分开**（切割归 `Panel.dxf`），
所以改动外壳参数后两张图都会同步重出。

### 5.1 设计：「星盘」

| 项 | 内容 |
|---|---|
| 底色 | 全幅近黑 `#08090A`（5 处开口和导光孔光圈处挖空，不印） |
| 线条 | 翡翠绿 `#35D98E` + 哑金 `#C9A94E`；最细 0.16 mm，最小圆点 φ0.44 |
| 字标 | 只有 **AgentDock** 一处文字（字高 2.75 mm，转轮廓），左下起点 (4.90, 36.55) |
| 键窗 ×3 | **不印任何文字**：每键上方三道同心环弧（r 11.0 / 12.3 / 13.6，自动裁掉扎进键窗的部分）+ 顶星点；键与键之间一道绿分隔线 + 圆点，两侧一道金立柱 + 菱形 |
| 旋钮 | 24 格刻度环（内金环 r8.2 / 外绿环 r9.0，四个正方位刻度加长变绿）+ 右下角一段轨道弧 φ11.3 |
| 导光孔 | 「STATUS 环」：金色环 φ6.7 + 绿色环 φ8.9 + 8 道刻度 + 未印刷光圈（r 1.8–3.35）；右侧 1.15 mm 字高的 `STATUS` |
| 其他 | 横向刻度基线（三键中心对称，±26 mm）、八芒星印记、外圈细金框（内缩 0.90 mm） |

### 5.2 导光孔为什么要「不印」

导光孔周围的 r 1.8–3.35 这一圈在印刷图里是**空的**（不是印白）。灯亮时，光从
φ3.6 的孔进入 1.5 mm 板体，被 **皇冠 #513 白色半透明背胶**散射，再从不印的这一圈
透出来 —— 光圈就是这么来的。所以：

* 背胶必须是**白色半透明**（#513 正好），透明胶不会有柔光效果
* 这一圈不能补印白色或黑色，补了就完全不透光

### 5.3 正面 / 背面印刷怎么选

| | 正面印刷（`..._front`） | 背面印刷（`..._back`） |
|---|---|---|
| 文件 | 图案即所见 | 已镜像，工厂直接印（备注「反面镜像」） |
| 耐刮 | 一般，建议加哑光保护层 | 最好，图案封在 1.5 mm 板内 |
| 观感 | 磨砂面更哑光、指纹少 | 正面是光面亚克力，黑底更深、更亮；灯亮时光圈更均匀 |
| 对位 | 印刷与切割在同一面，套准简单 | 需要工厂把切割图镜像后套准（常规工艺，下单时写明） |

### 5.4 下单前自检（脚本已强制）

`panel_print.py` 每次运行都会校验，不通过直接 `exit 1`：

* 所有线条离 5 处开口边 ≥ 0.40 mm（印到切口边上会崩边）
* 所有线条离面板外轮廓 ≥ 0.40 mm
* 最细线 ≥ 0.14 mm、最小点径 ≥ 0.36 mm
* PDF 页面尺寸严格等于 91.675 × 42.675 mm（1 数据单位 = 1 mm）

当前实测：最小间隙 **0.44 mm**、最细线 **0.16 mm**。

## 6. 两种可选做法

* **柔光窗**：现在是 φ3.6 通孔（会进一点灰）。因为亚克力本身透光，也可以**不开这个
  孔**，让 1.5 mm 磨砂亚克力当柔光窗，视觉更均匀。需要这版把 `enclosure.py` 里的
  `PANEL_LED_CUT` 设为 `0`，重出 DXF。
* **更矮的整机**：改用 1.0 mm 面板（`PANEL_T = 1.0`）→ 边框自动降到 1.2 mm，
  整机从 22.30 降到 21.70 mm（`RIM_H` 自动算成 1.20）。

## 7. 装配

1. 面板背面自带背胶（或单独裁 0.2 mm 3M 胶）。
2. 先别撕整片胶：把旋钮孔 / 导光孔套到位、三条键窗居中，再压合，避免有 5 个开孔
   时气泡难推。
3. 从一边向另一边压实，最后装旋钮（旋钮最后装，避免碍事）。

## 8. 改了参数之后

任何改动（外壳尺寸、键位、编码器/LED 位置、`PANEL_T`、`PANEL_GAP`、`RIM_W`）都必须：

```bash
uv run enclosure.py        # 重新生成 Panel.dxf + 自检（面板开孔 ≥ 顶盖开口）
uv run panel_drawing.py    # 重新生成尺寸核对图
uv run panel_print.py      # 重新生成印刷图（正面 / 背面 PDF+SVG）+ 核对图
```

`enclosure.py` 的自检会拦住「面板开孔小于顶盖开口」「面板与顶盖干涉」这两类错误，
CI 也会把 `Panel.dxf` 一起打进 `agentdock-hardware-<run>` 产物里。
